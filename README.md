# GitHub User Finder

**Автор:** [Андрей Грезенталь]

## Описание
GUI-приложение на Python (tkinter) для быстрого поиска пользователей GitHub и сохранения их в список избранных. Приложение использует публичный GitHub API.

## Функционал
1. Поиск пользователя по логину.
2. Отображение информации (логин, кол-во репозиториев, био).
3. Добавление пользователей в локальный список избранных.
4. Сохранение избранных пользователей в файл `favorites.json`.

## Как использовать API
Приложение использует GET-запросы к эндпоинту:
`https://api.github.com/users/{username}`

## Как запустить
1. Установите Python 3.
2. Установите зависимости: `pip install requests`.
3. Запустите: `python main.py`.

## Примеры использования
1. Введите `octocat` в поле поиска.
2. Нажмите "Найти".
3. Нажмите "Добавить в избранное".
